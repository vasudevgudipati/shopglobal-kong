# Getting started

The ShopGlobal Marketplace API gives you products, orders, returns and saved addresses.

**Base URL (UAT):** `https://shopglobal-api-uat.pronteff.com:8443`

## Try it

```bash
curl https://shopglobal-api-uat.pronteff.com:8443/api/categories
```

You get back the list of product categories.

## Authentication

UAT is open while we test. Login with Keycloak is added in a later release.
