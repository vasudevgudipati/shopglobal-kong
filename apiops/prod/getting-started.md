# Getting started

The ShopGlobal Marketplace API gives you products, orders, returns and saved addresses.

**Base URL:** `https://shopglobal-api.pronteff.com:8443`

## Try it

```bash
curl https://shopglobal-api.pronteff.com:8443/api/categories
```

You get back the list of product categories.

## Authentication

Every call needs an OAuth 2.0 bearer token from Keycloak.
